# 計畫：從 Composio/awesome-claude-skills 補齊通用技能空缺

日期：2026-07-31
背景：使用者一度考慮改用 CODEX（嫌 Claude Code 介面複雜、無中文版），
後決定保留本倉庫（繁體中文專化是獨特資產），改為研究 ComposioHQ/awesome-claude-skills
（71k star，1000+ skills）找出本倉庫的通用工作流空缺並補齊。

## 目標

在不破壞現有 63 個技能與六層結構的前提下，新增 5 個「通用工作流」技能，
填補經研究確認的真空缺領域，並提供繁體中文版本（非單純外部連結）。

## 範圍確認（研究結論）

researcher subagent 調查 ComposioHQ/awesome-claude-skills 後確認：
- 本倉庫「資料與分析」marketplace 分類（data-analytics）目前 7 個技能全是台灣物業會計專用
  （銀行對帳、薪資、稅務…），**通用資料分析是真空缺**
- 履歷／招聘、測試自動化擴充、專案協作／知識庫、通用 API 串接 為次要空缺
- CRM/電商/客服在 Composio 裡只有自動生成連接器（無業務邏輯），不具參考價值，故不追加

## 新增技能清單（5個，優先度排序）

1. **csv-data-analyzer-skill**（資料分析）— CSV/表格資料自動摘要、異常值抓取、生成圖表洞察
2. **root-cause-tracing-skill**（問題根因追蹤）— 錯誤/异常從表象往回溯源頭的結構化方法
3. **resume-tailor-skill**（履歷客製化）— 依職缺 JD 調整履歷內容與關鍵字
4. **tdd-workflow-skill**（測試驅動開發）— 先寫測試後寫實作的 TDD 工作流指南
5. **test-fixing-skill**（測試修復）— 自動診斷並修復失敗測試案例

每個技能：
- 資料夾命名沿用現有慣例（`<name>-skill`）
- `SKILL.md` 繁體中文撰寫，frontmatter 含 `name` + `description`
- 內容原創改寫（非逐字翻譯 Composio 原文，避免授權疑慮），僅參考其功能定位
- 註冊進 `.claude-plugin/marketplace.json`（category: `data-analytics` x2、
  `productivity-organization` x1、`development-tools` x2）
- 加入 `README.md` 對應章節 + `INDEX.md` 分類表
