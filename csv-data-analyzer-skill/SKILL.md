# CSV 資料分析器

快速理解一份陌生 CSV／Excel 資料的結構、品質與重點洞察，不需要使用者先告訴 Claude 要看哪一欄。

## 何時使用此技能

- 拿到一份陌生的 CSV／表格，想先知道「這份資料在講什麼」
- 懷疑資料有缺漏值、重複列、格式不一致等問題
- 需要在動手做進一步分析（樞紐分析、報表）前先做資料品質檢查
- 想要一份「資料摘要報告」給主管或同事看，而不是丟一整份原始表格

## 分析流程

1. **結構掃描**：讀取欄位名稱、資料型別（數字/文字/日期）、列數，判斷每欄是類別型還是數值型
2. **品質檢查**：
   - 缺漏值比例（哪些欄位缺最多）
   - 重複列
   - 格式不一致（例如同一欄日期格式混用、數字欄夾雜文字）
   - 離群值（數值欄用四分位距或標準差抓出異常點）
3. **摘要統計**：
   - 數值欄：平均、中位數、最大最小值、分布
   - 類別欄：各類別出現次數、佔比最高的前幾名
   - 日期欄：時間範圍、資料是否連續
4. **重點洞察**：用 1-3 句話點出「這份資料最值得注意的地方」（例如某欄缺漏率異常高、
   某個類別佔比過度集中、有明顯離群值）
5. **視覺化建議**（如使用者要求圖表）：依資料型態建議適合的圖表類型
   （類別分布用長條圖、趨勢用折線圖、分布用直方圖），並實際產生圖表

## 輸出格式

預設輸出精簡的文字摘要（不是把整份原始資料貼回去）：

```
📊 資料摘要：<檔名>
- 筆數／欄位數：xxx 筆 × xx 欄
- 資料品質：缺漏 X 欄需注意、重複列 Y 筆
- 關鍵欄位摘要：<欄位> 平均/中位數/分布…
- ⚠️ 需要注意：<最值得關注的 1-3 個發現>
```

如果使用者要進一步深入某一欄或做交叉分析，再依需求延伸，不要一次全部攤開。

## 注意事項

- 大型檔案（超過可一次讀入的大小）先用抽樣或分批讀取，不要嘗試把整份塞進 context
- 涉及金額/個資欄位時，摘要中避免整欄印出，改用統計值呈現
- 若資料有明顯業務脈絡（例如像帳款、薪資），優先參考本倉庫對應的財務會計技能
  （如 bank-reconciliation-skill、budget-variance-skill），本技能專注在「通用、未知結構」的資料
