# 履歷客製化

針對單一職缺說明（JD）調整既有履歷，讓相關經驗與關鍵字更突出，而不是每次投遞都用同一份泛用履歷。

## 何時使用此技能

- 手上已有一份基礎履歷，要投遞特定職缺，想針對該職缺調整
- 想知道履歷跟 JD 之間哪裡「對得上」、哪裡「明顯缺」
- 履歷內容都真實存在，只是需要重新排序/措辭讓重點更清楚
- 同時要投多個職缺，需要幫每個職缺客製化一版

## 客製化流程

1. **拆解 JD**：列出職缺說明裡的關鍵要求——必要技能、加分項、常出現的關鍵字、
   職責描述的用詞習慣
2. **比對現有履歷**：
   - 哪些經驗直接對應 JD 要求 → 應該往前排、用詞對齊 JD 用語
   - 哪些經驗間接相關 → 調整措辭凸顯關聯性
   - 哪些 JD 要求履歷完全沒提到 → 誠實列出「缺口」，不要編造沒有的經驗
3. **調整重點**（只調整呈現方式，不捏造事實）：
   - 重新排序工作經歷中的條列項目，把最相關的放前面
   - 用 JD 裡出現的詞彙替換履歷裡意思相同但用詞不同的表達
   - 量化成果的地方盡量保留/強化數字（例如「提升 20% 效率」比「提升效率」有力）
4. **輸出對照報告**：列出「這次改了什麼、為什麼改」，讓使用者能一眼看出差異，
   而不是直接吐出一整份改完的履歷讓人自己比對

## 輸出格式

```
📄 履歷客製化：<職缺名稱>
✅ 高度對應：<履歷中直接符合 JD 的經驗，已調整用詞/排序>
🔧 已調整：<具體改了哪幾條、原因>
⚠️ 缺口：<JD 要求但履歷沒有對應經驗的部分——誠實列出，不編造>
```

## 注意事項

- **絕不捏造經驗、職稱、任職時間或數字**——客製化只調整措辭與排序，
  內容必須完全基於使用者提供的真實履歷資訊
- 如果 JD 要求的關鍵經驗真的沒有，誠實告知這是缺口，可以建議在求職信或面試中如何應對，
  而不是硬把履歷寫得好像有
- 涉及具體檔案格式輸出（Word/PDF）時，可搭配本倉庫的 document-skills 完成排版
